Instalar SMKTRON

Mellotron lo-fi com layers, acordes nos pads, sequenciador e efeitos. A primeira instalação exige M-VAVE V016. Confira 0.3.0-gr3 no boot após instalar.

Retornar ao M-VAVE V016

Usa exatamente o arquivo original que você escolheu acima. Confere a identidade após reiniciar.

As operações serão habilitadas após as conferências.

A retomada de uma operação interrompida exige carregar novamente o V016 e usar este mesmo navegador. Um loader desconhecido permanece bloqueado.

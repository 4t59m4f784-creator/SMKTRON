Novidades da versão

0.3.0-ml1 · MIDI LAYERS · SMK-37 Pro_463

Banco B dos pads seleciona canais 1–16 e combina layers instantâneos. Pitch bend, modulação e sustain acompanham o layer.

Toque em um pad para escolher um canal. Segure um pad e adicione outros para formar um layer; solte para manter. Um novo toque sozinho seleciona um único canal.

Mellotron lo-fi com layers, acordes nos pads, sequenciador e efeitos. Para quem ainda não usa SMKTRON, a primeira instalação exige M-VAVE V016. Confira 0.3.0-ml1 no boot após instalar.

A retomada de uma operação interrompida exige carregar novamente o V016 e usar este mesmo navegador. Um loader desconhecido permanece bloqueado.

Depois da instalação

Para usar o MIDI Layers

GLOBE → MIDI MODE → K1 à direita. Pressione KNOB BANK + FADER BANK juntos para acessar o banco B dos pads. O canal principal fica em GLOBE/K3; editar um controle em PARA/K3 muda apenas esse controle.

Para usar o pedal de sustain

Conecte o pedal solto antes de ligar para calibrar a polaridade. No controlador, sustain e rodas acompanham os canais do layer. GLOBE + SEQ PLAY envia MIDI PANIC.

A seleção do layer é temporária. Ao entrar novamente no controlador ou alterar GLOBAL/K3 ou o mapa, volta um único canal principal. BT salva os quatro mapas; o backup musical não inclui os mapas MIDI.

Créditos e licenças

O SMKTRON surgiu do excelente FMEL-1 para o FM-1, que consegue soar muito bem em um dispositivo com tão pouco armazenamento. A proposta do SMKTRON foi ajustar alguns samples e, principalmente, adaptar a interface e os controles para um instrumento focado em performance no M-VAVE SMK-37 Pro.

Concepção, direção musical e testes: Marcus Padrini. Desenvolvimento das adaptações, interface, controles, documentação e ferramentas web com participação do ChatGPT/Codex (OpenAI). Os projetos e autores originais permanecem creditados por suas contribuições.

Base: FMEL-1 / AntonioAltea; port SMK-37 / genkigenki; Dinghy e OberVave / zvenson; Felucca / Hügelton Instruments; SLOOP / isod89. Reverb baseado no algoritmo de Jon Dattorro.

Código derivado: GPL-3.0-only. Samples de Mellotron: Bernie Kornowicz (Taijiguy), com termos próprios de uso não comercial. Os samples não são GPL nem domínio público. Fontes e componentes mantêm suas licenças.

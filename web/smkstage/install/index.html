Primeiro firmware experimental Hammond B3 para M-VAVE SMK-37 Pro. Instalação controlada pelo navegador usando USB-MIDI.

ALPHA · NÃO TESTADA NO HARDWARE

Esta é uma versão de desenvolvimento. O código compilou, mas ainda não foi testado no SMK-37 físico. Pode não iniciar, perder dados ou exigir recuperação USB. O projeto não está liberado para distribuição pública.

Somente SMK-37 Pro. Não instale no Elite, MKE-P37 ou FM1. Antes de prosseguir, faça backup dos presets e reserve o V016 original para retorno.

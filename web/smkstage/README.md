# SMKSTAGE B3 Simulador 0.3

Protótipo online independente do firmware instalável SMKSTAGE. Engine WebAssembly original de [R-Jeb/setBfree-fm1](https://github.com/R-Jeb/setBfree-fm1), commit `4dd709b18b24cb5934dd57796ac65940722d9383` (GPL-3.0-only), também derivada de [setBfree](https://github.com/pantherb/setBfree) (GPL-2.0-or-later). Código-fonte e avisos de licenças nos respectivos repositórios.

Limitações 0.3: a build upstream WASM expõe apenas o manual Upper no áudio; Lower e Pedal são prévias de registro, não os motores corretos. Leslie OFF usa STOP. EQ visual não integrado. Ainda não é firmware do SMK-37.

Publicado temporariamente nesta subpasta do SMKTRON pela ausência de criação de repositórios na conexão GitHub. A publicação não altera o firmware SMKTRON.

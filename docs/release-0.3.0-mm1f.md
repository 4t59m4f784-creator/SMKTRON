## Português

MIDI MODE passa a integrar a versão oficial do SMKTRON. Firmware MM1f aprovado nos testes físicos de Marcus Padrini, publicado com os mesmos bytes e identidade **SMK-37 Pro_460**. Confira **0.3.0-mm1f** no boot.

- Modos exclusivos: synth sem MIDI musical; controlador sem áudio interno.
- USB e TRS OUT, quatro mapas editáveis no teclado, ABS/REL, bancos A/B, cores de pads, velocity, pitch bend, modulação, sustain e Panic.
- Telas ampliadas em GLOBAL, entrada e edição, com Zoom.
- K5 corrigido: seus passos pertencem ao controlador durante MIDI MODE; volume do synth preservado.
- Sons, samples, efeitos, GRAIN, sequenciador, layers, cenas e acordes preservados.
- Site, simulador, instalador, changelog e manual no GitHub Pages. Manual MIDI inclui guia em inglês e capturas reais.

Primeira instalação via V016 oficial M-VAVE; GR3 e demais versões SMKTRON reconhecidas podem atualizar diretamente pelo [instalador](https://4t59m4f784-creator.github.io/SMKTRON/install/). Selecione seu V016 original para retorno; ele não é redistribuído. Apenas SMK-37 Pro; Chrome/Edge no computador e cabo USB de dados. Nenhuma escrita começa sem confirmação. Mapas MIDI são salvos separadamente e não integram o backup musical. Sem Bluetooth MIDI.

## English

Official SMKTRON now includes MIDI MODE. Physically approved MM1f published with identical firmware bytes, identity **SMK-37 Pro_460**. Check **0.3.0-mm1f** at boot.

Exclusive synth/controller modes; USB/TRS OUT; four on-device editable maps; ABS/REL; A/B banks; pad colours; velocity, bend, modulation, sustain and Panic. Larger controller screens with Zoom. Fixes K5 events being consumed by the synth volume reader. All previous sounds and performance features retained. Website, simulator, installer and manual hosted on GitHub Pages.

First installation requires official V016; GR3 and recognized SMKTRON versions can update directly. SMK-37 Pro only; desktop Chrome/Edge and USB data cable. Supply your original V016 restore file; writes require confirmation. MIDI maps have separate storage and are excluded from musical backups. No Bluetooth MIDI.

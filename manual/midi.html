27 / MIDI

MIDI MODE / Controlador

Use o SMKTRON como instrumento ou como controlador MIDI independente. O teclado sempre inicia no modo synth.

Synth: áudio ativo; nenhum MIDI musical é transmitido ou interpretado. MIDI MODE: áudio silencioso; teclas e controles enviam MIDI por USB e TRS. A identificação e atualização USB continuam disponíveis nos dois modos.

Entrar e sair

  1. GLOBE percorre SETUP → SYSTEM → PAD CHORDS → MIDI MODE, a quarta página GLOBAL.
  2. Na página MIDI MODE, gire K1 à direita para entrar. Sequência, gravação e notas sustentadas do synth são interrompidas.
  3. No controlador, GLOBE abre MIDI GLOBAL; K1 à esquerda volta ao synth. Solte teclas, pads e pedal ao alternar. A sequência não reinicia automaticamente.

GLOBAL: quatro knobs

KnobFunção
K1 MODEEsquerda: voltar ao synth.
K2 MAPMapa independente 1–4.
K3 CHCanal principal MIDI 1–16.
K4 KNOBSABS: valores 0–127 e aceleração por encoder. REL: incrementos/decrementos em torno de 64; o receptor deve usar a mesma convenção.

BT salva os quatro mapas. REC pede confirmação para restaurar o mapa atual: BT confirma, PATCH cancela. GLOBE volta à execução MIDI.

Editar sem computador

  1. Pressione PARA e toque o controle: gire encoder, mova fader/roda ou toque pad/botão. Controles reservados à navegação não são remapeáveis.
  2. K1 TYPE: OFF, CC, TOGGLE, NOTE ou BEND, conforme o controle. Encoders/faders usam CC ou OFF. Pads também permitem CC alternado e nota. Pitch wheel permite BEND de 14 bits.
  3. K2 CC / NOTE: número 0–127. K3 CH: canal próprio 1–16 ou MAIN, seguindo o canal principal. K4 COLOR: cor do pad; AUTO usa cor por função. “--” indica campo sem aplicação.
  4. K5 seleciona outro controle; PATCH volta à escolha por toque; PARA encerra a edição. BT salva: “SAVED” confirma. Solte teclas, pads e pedal antes de salvar.

Bancos e execução

  • KNOB BANK alterna A/B dos oito encoders. FADER BANK alterna A/B dos quatro faders. Ambos juntos alternam A/B dos 16 pads: 16 encoders, 8 faders e 32 pads lógicos por mapa.
  • 37 teclas com velocity; OCT −/+ transpõe o teclado do controlador em até três oitavas para cada lado.
  • Pitch bend, modulação e sustain funcionam no controlador. Conecte o pedal solto antes de ligar para calibrar a polaridade. Sustain transmite CC64 no canal principal.
  • GLOBE + SEQ PLAY: MIDI PANIC, para liberar notas externas.
  • K5 pertence exclusivamente ao controlador durante MIDI MODE; não muda o volume guardado do synth.

Conexões, memória e simulador

USB e TRS enviam as mesmas ações. TRS é saída: conecte à entrada MIDI do receptor com cabo/adaptador compatível. Não há TRS MIDI IN, Bluetooth MIDI, MIDI Thru, Mackie/HUI ou retorno de estado da DAW.

Os quatro mapas são salvos separadamente de timbres, cenas e acordes. Salvar o boot do synth não salva mapas MIDI: use BT no controlador. O backup musical não inclui mapas MIDI.

No simulador, inicie a sessão, clique MIDI MODE e use Conectar MIDI para escolher uma saída Web MIDI. Mapas do navegador não são transferidos automaticamente ao teclado físico. MIDI recebido não dispara o instrumento nesta versão. Feche a sessão MIDI/áudio do simulador antes de usar o instalador.

English — MIDI MODE guide

Boot starts in synth mode: internal audio, no musical MIDI input/output. Controller mode silences audio and sends keys, controls, wheels and sustain through USB and TRS OUT. Technical USB identity/update remains available. No Bluetooth or TRS IN.

GLOBE cycles SETUP → SYSTEM → PAD CHORDS → MIDI MODE. K1 right enters. In the controller, GLOBE opens GLOBAL: K1 left returns to synth; K2 selects map 1–4; K3 main channel 1–16; K4 ABS/REL. ABS accelerates per encoder; REL uses 64-centred signed increments and needs a matching receiver setting. REC requests current-map defaults; BT confirms and PATCH cancels.

PARA edits; touch the control to select it. K1 type; K2 CC/note number; K3 dedicated channel or MAIN; K4 pad colour. K5 selects another control; PATCH picks by touch. PARA returns. BT explicitly saves all four maps: release keys, pads and pedal first. “SAVED” confirms. OFF/CC/TOGGLE/NOTE/BEND availability depends on control type.

KNOB BANK and FADER BANK select their A/B banks; press both for pad bank A/B. Keys transmit velocity; OCT changes controller octave ±3. Connect sustain pedal released before boot for automatic polarity; sustain sends CC64 on main channel. GLOBE + SEQ PLAY sends Panic. Switching modes stops recording, sequence and held notes; release controls after switching. K5 in MIDI never changes synth volume.

Maps use separate storage and are excluded from the musical-state backup. Browser maps do not transfer automatically to hardware. Start the simulator, choose MIDI MODE and a Web MIDI output. Incoming MIDI does not play the synth. No MIDI Thru, DAW feedback or Mackie/HUI.
